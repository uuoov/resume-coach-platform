# 产品设计方案

## 1. 产品定位

**Resume Coach Platform** - AI 驱动的简历辅导平台，专注于**针对公司 + 岗位的定向简历优化**。

### 核心价值主张

- **一岗一版**: 为每个投递的岗位生成定制化简历
- **公司维度定制**: 分析公司背景、文化、技术栈
- **岗位维度定制**: 深度解析 JD，提取关键词和能力要求
- **AI + 人工审核**: AI 生成建议，可选人工顾问审核

### 2.2 异常流程处理

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         异常流程处理                                    │
└─────────────────────────────────────────────────────────────────────────┘

【简历解析失败】
上传 → 解析失败 → 提示用户 → 提供手动输入入口

【JD 解析失败】
输入 JD → AI 解析失败 → 降级到关键词提取 → 提示用户补充信息

【匹配度过低】
计算匹配度 → 低于 40 分 → 提示用户 → 建议调整岗位目标或补充技能

【API 超时】
调用 AI → 超时 → 自动重试 (3 次) → 仍失败 → 提示用户稍后重试
```
